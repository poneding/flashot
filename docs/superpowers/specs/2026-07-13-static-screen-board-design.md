# 画板设计

## 目标

新增一个不改变现有区域截图行为的画板入口。用户按下独立快捷键后，Flashot 将鼠标所在显示器的当前画面冻结，并立即在整屏范围内进入标注状态。

## 用户流程

1. 用户在任意应用中把鼠标移到目标显示器。
2. 按下画板快捷键，默认是 macOS 的 `Option+B`，以及 Windows/Linux 的 `Win+B`。
   用户也可以从 menubar 菜单选择“画板”进入相同流程。
3. 目标显示器全屏显示冻结画面，其他显示器不被覆盖。
4. 标注工具栏默认显示在目标屏幕顶部居中；若 macOS 目标屏幕存在刘海安全区，则自动下移避让。关闭/保存/复制操作栏纵向显示在屏幕右侧居中；两者均可拖动。
5. 画板默认激活画笔并展开颜色、粗细子工具栏。用户可以使用现有标注工具、撤销和重做，每项标注工具打开的子工具栏也在屏幕中水平居中。
6. `Esc` 关闭画板；复制或保存会把整屏冻结帧和标注合成后输出，并结束会话。

## 功能边界

- 多屏支持指快捷键始终选择鼠标所在显示器，而不是固定选择主显示器。
- 画板范围固定为目标显示器的完整逻辑像素矩形，不能移动或缩放。
- 复用现有冻结帧、Overlay、标注画布、裁剪输出和 `SessionGuard` 清理机制。
- 画板不显示仅适用于截图选区的圆角、贴图、取色器、图像调整和滚动截图入口。
- 同一时间仍只允许一个捕获或画板会话。
- 区域截图快捷键、状态机、多屏选区所有权和工具栏默认布局保持不变。

## 验收标准

- 可在设置中查看、修改、清空和重置画板快捷键，并参与快捷键冲突检测。
- menubar 菜单在“截取当前活动窗口”下方提供带图标和当前快捷键提示的画板入口。
- 在任意显示器触发时，仅该显示器出现全屏冻结画板。
- 画板打开后可以绘制、撤销、重做、删除、复制、保存和退出。
- 有刘海的 macOS 笔记本内置屏幕会根据 `NSScreen.safeAreaInsets.top` 下移标注工具栏，非刘海屏幕不产生额外偏移。
- 画板默认激活画笔并显示颜色、粗细子工具栏，标注工具的子工具栏水平居中；截图模式的工具选择和工具栏位置保持不变。
- 画板边缘点击或拖动不会改变整屏范围。
- 复制和保存结果尺寸等于目标显示器的完整截图尺寸，并包含标注。
- 原有区域截图、快速截屏和活动窗口截屏测试继续通过。
